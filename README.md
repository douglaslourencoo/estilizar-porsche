
# 🚗 Estilização de Interface Inspirada na Porsche

## 📊 Visão Geral

Este projeto consiste na criação de uma interface web estilizada inspirada no design da Porsche, com foco em **UI moderna, responsiva e visual de alto impacto**.

O objetivo é explorar conceitos de **design visual, front-end e experiência do usuário (UX/UI)** aplicando uma estética premium baseada em marcas automotivas de luxo.

---

## 🎯 Objetivo do Projeto

- Desenvolver uma interface visualmente elegante e minimalista
- Aplicar princípios de design inspirados na Porsche
- Explorar composição visual, tipografia e cores
- Criar experiência de usuário fluida e responsiva

---

## 🧠 Conceitos Aplicados

- UI/UX Design
- Design System (inspiração Porsche)
- Responsividade (Mobile First)
- Hierarquia visual
- Estética minimalista premium
- Componentização de interface

---

## 🧰 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (básico/interatividade, se aplicável)  
- Flexbox / Grid Layout  

---

## 🎨 Características da Interface

- Layout moderno e responsivo <br>
- Paleta de cores inspirada em marcas automotivas premium <br>
- Tipografia elegante e de alto contraste <br>
- Elementos visuais com foco em performance estética <br>
- Estrutura limpa e minimalista <br>
